# TINDAHAN Android

This is the Android-ready TINDAHAN project using Capacitor. The existing TINDAHAN MVP web app is packaged as a native Android application shell.

## Build

1. Install Node.js 22+ and Android Studio/Android SDK.
2. In this folder run `npm install`.
3. Run `npm run android:add` once.
4. Run `npm run android:sync` after web changes.
5. Run `npm run android:open` to open the Android project.
6. For a test APK use Android Studio's Build APK action.
7. For Google Play, create a signed Android App Bundle (AAB).

The app ID is `com.tindahan.app` and the display name is `TINDAHAN`.
